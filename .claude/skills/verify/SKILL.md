---
name: verify
description: Verify changes in Gurrulabs Websites (static site). Use after implementing anything and before writing a ticket Summary.
---

Run from the repo root, stopping at the first failure. Pages are generated by `scripts/build.mjs` and committed.

1. Generate and validate: `node scripts/build.mjs` (then `git status --short`: a second run must change nothing),
   then `node scripts/validate.mjs` (pages in 4 locales, canonical/hreflang, sitemap, every page tracked: `<body data-page=<slug> data-locale>`
   + `/script.js`, Play links have `data-cta` and `data-app`,
   Mixpanel gate, banned claims). Must print `validate: OK`. A new page must be added to `PAGES`
   in the validator, or it is not checked.
2. Serve and probe: `python3 -m http.server 8765` in the background, then `curl -s -o /dev/null -w "%{http_code}" http://localhost:8765/<path>`
   for `/`, every page the ticket added or changed in all 4 locales (en, es, fr, pt), and new assets. Each must be `200`. Stop the server after.
3. JS syntax: `node --check script.js` and `node --check` for each changed `scripts/*.mjs`.
4. Diff check: `git diff --stat main...HEAD` plus uncommitted diff. Confirm every page change exists in en/es/fr/pt
   and no ticket files (`.lead/tickets/T-*.md`) are staged. Edit copy in `scripts/build.mjs`, never in the generated HTML.
5. Publish check: every new top-level internal file/folder is listed under `exclude:` in `_config.yml` (dot-folders are never published).
6. Analytics gate: never load pages on https://www.gurrulabs.com during checks; on localhost `window.mixpanel` must stay undefined.
7. Visual check for UI tickets: headless Chrome screenshots at 390px and desktop
   (`"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --window-size=390,844 --screenshot=<out.png> <url>`).
   If Chrome is unavailable, say "not visually verified".

Report: each command, pass/fail, and the relevant excerpt of failing output (≤20 lines).
If a command cannot run here, say so explicitly — never report it as passed.
